Every semester, college students, ourselves included, face the challenge of balancing academics with sleep, exercise, and social activities while maintaining strong academic performance. Much of the advice surrounding this balance is general, such as getting more sleep, spending less time on phones, or starting assignments earlier. However, this advice rarely quantifies how these trade-offs actually affect academic performance. In this project, we approach this question as a supervised regression problem: given students' self-reported daily habits and background characteristics, how accurately can we predict their academic performance and outcomes?
